# Hyprland Lua port

The full hyprlang config ported to Lua, written for **Hyprland 0.56** (your
current version). It also works on 0.57, which drops `.conf` support.

## Where things go

`HOME/` mirrors your home folder: `lua-port/HOME/X` goes to `~/X` (`/home/pulkit/X`).

| In this repo | On the Linux machine | What it is |
|---|---|---|
| `HOME/.config/hypr/hyprland.lua` | `~/.config/hypr/hyprland.lua` | Main config. Hyprland loads it instead of `hyprland.conf` |
| `HOME/.config/hypr/conf/*.lua` | `~/.config/hypr/conf/` | monitors, autostart, env, input, general, animations, keybindings, windowrules, userprefs, plus `hyde.lua` (shared helpers) |
| `HOME/.config/hypr/themes/{common,theme,colors}.lua` | `~/.config/hypr/themes/` | Replace `common.conf`, `theme.conf` and `colors.conf`. `theme.lua` and `colors.lua` are generated by HyDE from now on |
| `HOME/.config/hypr/.luarc.json` | `~/.config/hypr/` | Autocompletion for the `hl.` API in editors (optional) |
| `HOME/.config/hyde/themes/<Theme>/hypr.theme` | `~/.config/hyde/themes/<Theme>/` | All 10 themes, now in Lua (Rule One's `hypr-theme.back` too) |
| `HOME/.config/hyde/wallbash/Wall-Dcol/hypr.dcol` | same path under `~` | Wallbash template that now writes `colors.lua` |
| `HOME/.local/share/bin/*.sh` (5 scripts) | `~/.local/share/bin/` | `dontkillsteam`, `windowpin`, `gamemode`, `touchpadtoggle`, `wallbashqt` |
| `tools/patch-in-place.py` | run it, don't copy it | Exact small edits to `swwwallbash.sh`, `themeswitch.sh`, `swwwallpaper.sh`, `wbarstylegen.sh`, `gamelauncher.sh`, `sysmonlaunch.sh`, 3 waybar files and 2 wlogout layouts (keeps a `.hyprlang.bak` copy of each) |
| `tools/install.sh`, `rollback.sh`, `verify-binds.sh` | run them | See below |

`hyprland.conf`, `hyprlock.conf`, `themes/mocha.conf` and your other files are left alone.

## Install

```sh
bash lua-port/tools/install.sh     # backs up, copies, patches
# then log out and back in   (or: hyprctl reload full-reset)
bash lua-port/tools/verify-binds.sh
```

`install.sh` first saves everything it touches to `~/hypr-lua-port-backup-<time>.tar.gz`.
`verify-binds.sh` prints `hyprctl configerrors` and checks all 127 binds against
your old ones (`binds-before.json`).

Undo: `bash lua-port/tools/rollback.sh`, then log out and back in.

## Keybindings

Every bind is ported 1:1: same keys, flags, order and commands, duplicates
included (Super+Alt+C and Super+Alt+R both toggle `chatgptWin`, and neither
causes problems). I checked all 127 against `binds-before.json`.

Under a Lua config, `hyprctl dispatch` only accepts Lua, and `hyprctl keyword`
stops working entirely. So the scripts behind these binds had to change, but
the binds themselves didn't:

| Bind | Script | Change |
|---|---|---|
| Super+Q, Alt+F4 | `dontkillsteam.sh` | `dispatch killactive` → `dispatch 'hl.dsp.window.close()'` |
| Super+Shift+F | `windowpin.sh` | `togglefloating` / `pin` → Lua dispatchers |
| Ctrl+Alt+arrows | (inline) | `hyprctl keyword monitor eDP-1,...` → `hyprctl eval 'hl.monitor({...})'` (same rule, doubled line kept) |
| F6 | `touchpadtoggle.sh` | `keyword device[...]:enabled` → `eval 'hl.device({...})'` |
| Super+Alt+G | `gamemode.sh` | `--batch keyword ...` → `eval 'hl.config({...})'` |
| Ctrl+Shift+Esc | `sysmonlaunch.sh` | read the terminal name from `keybindings.lua` instead of `keybindings.conf` |
| Super+Alt+←/→, Super+Shift+T/W/R | `swwwallbash.sh`, `themeswitch.sh` | `keyword misc:disable_autoreload` → `eval` |
| waybar scroll, updates click, wlogout logout | config files | `hyprctl dispatch ...` → Lua dispatchers |

## What changed on purpose (the silent bugs)

- **Shadows**: every theme used removed keys (`drop_shadow`, `shadow_range`, `col.shadow`…), so shadows were always on. They're now `decoration.shadow.*`. Edge Runner, Material Sakura and Synth Wave have shadows; the other themes don't.
- **Waybar blur**: `layerrule = blur,waybar` / `blurls` were old syntax and ignored. Catppuccin Mocha, Frosted Glass, Nordic Blue, Synth Wave and Tokyo Night now blur waybar. Rule One (your current theme) doesn't, same as before.
- **GTK theme race**: theme and wallbash used to run `gsettings` at the same time, so the result was random. They now run in order, and wallbash (`colors.lua`) wins when wallbash mode is on.
- **Lock-screen background**: `swwwallpaper.sh` was meant to set hyprlock's background to the current wallpaper, but used an undefined variable. It now works, but only for the background; the avatar stays `finalizer.png`. If you'd rather keep `finalizer.png` as the background too, delete the last `sed -i ...hyprlock.conf` line in `swwwallpaper.sh`.
- **Removed**: `env = bitdepth,10` (did nothing), the `hyprwinwrap` plugin block (plugin not installed), `pseudotile` (removed from Hyprland), `shadow_ignore_window` (removed), `nvidia.conf` (as you asked).
- **PATH** is only extended once, so reloading the config no longer keeps growing it.
- **`exec-once`** commands now run on the `hyprland.start` event. Top-level Lua runs on every reload, so without this, every reload would start another waybar, dunst, kmonad and so on.

## Notes

- Correction to my earlier review: your laptop panel (eDP-1) only supports 1920x1080@60, so the fallback monitor rule was never forcing it below native resolution. That `2880x1800` line came from the HyDE template. Monitors are ported as-is. Your LG can do 2560x1440@**99.95**Hz; there's a commented hint in `conf/monitors.lua`.
- `keybinds_hint.sh` isn't bound to any key and reads `.conf` files, so it's left as is.
- Hyprspace (hyprpm) isn't referenced anywhere in the config. After the 0.57 update it needs `hyprpm update`, or you can disable it with `hyprpm disable Hyprspace`.
- Most config errors now appear as an error bar instead of being silently skipped. If you ever end up with no binds, Hyprland's emergency binds are Super+Q (terminal) and Super+M (exit).
